# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability-reporting flow for this repository when it is available.
If it is unavailable, wait for a private reporting channel to be published
before sharing exploit details publicly.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Reports are acknowledged as soon as practical and handled
confidentially.
